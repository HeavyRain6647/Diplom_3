# Финальный дипломный проект: Лента заказов Stellar Burgers (Часть 3)

Заключительный этап дипломной работы, посвященный тестированию динамического функционала: Ленты заказов, счетчиков и взаимодействия между разделами сервиса.

## 🛠 Технологии и инструменты
* **Язык:** Python 3.x
* **Тест-фреймворк:** Pytest
* **Инструмент автоматизации:** Selenium WebDriver
* **Архитектура:** Page Object Model (POM)

## 🧪 Что протестировано в проекте:

### 1. Конструктор и ингредиенты (`test_constructor.py`):
* Работа переключателей разделов («Булки», «Соусы», «Начинки»).
* Открытие и закрытие модального окна с деталями ингредиента при клике.
* Валидация отображения информации об ингредиенте в модальном окне.

### 2. Лента заказов (`test_order_feed.py`):
* Отображение модального окна с деталями заказа при клике на него в Ленте.
* Отображение заказов пользователя из «Истории заказов» в общей «Ленте заказов».
* Работа счетчиков «Выполнено за все время» и «Выполнено за сегодня» (увеличение при создании нового заказа).
* Появление номера нового заказа в разделе «В работе» после его оформления.

### 3. Личный кабинет:
* Проверка функционала «Истории заказов» и корректность отображения данных пользователя.

## 📂 Структура проекта
* `locators/` — локаторы для страниц Конструктора, Ленты заказов и Личного кабинета.
* `pages/` — методы для работы с динамическими элементами и модальными окнами.
* `tests/` — комплексные сценарии тестирования.
* `conftest.py` — фикстуры для настройки драйвера и тестовых данных.
