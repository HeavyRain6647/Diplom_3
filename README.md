# Финальный дипломный проект: Автоматизация ленты заказов Stellar Burgers

Третья часть дипломной работы, сфокусированная на тестировании сложного функционала: ленты заказов, модальных окон и счетчиков.

## 🛠 Стек технологий
* **Python 3.x**
* **Pytest**
* **Selenium WebDriver**
* **Page Object Model (POM)**

## 🧪 Что протестировано в этом проекте:

### 1. Конструктор и заказы (`test_constructor.py`):
* Переходы по разделам «Булки», «Соусы», «Начинки».
* Появление модального окна с деталями ингредиента при клике.
* Закрытие модального окна (клик по крестику).

### 2. Лента заказов (`test_order_feed.py`):
* Открытие модального окна с деталями заказа при клике на него в ленте.
* Отображение заказов пользователя из истории в «Ленте заказов».
* Обновление счетчиков «Выполнено за все время» и «Выполнено за сегодня» при создании нового заказа.
* Появление номера нового заказа в разделе «В работе» после его оформления.

### 3. Личный кабинет:
* Проверка раздела «История заказов» и корректность отображения данных.

## 📂 Структура проекта
* `locators/` — вынесенные локаторы элементов для удобной поддержки.
* `pages/` — объектно-ориентированное описание страниц сервиса.
* `tests/` — тестовые сценарии на Pytest.
* `conftest.py` — фикстуры для инициализации драйвера и подготовки тестовых данных.

## 🚀 Как запустить тесты
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите тесты: `pytest`
